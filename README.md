# AutoCare Pro for Windows

[Download the latest Windows installer](https://github.com/006shido/AutoCare-Pro/releases/latest)

Download the **AutoCare-Pro-VERSION.msi** asset, open it to install, and launch AutoCare Pro from the desktop or Start menu. Java is included. Windows 64-bit and an internet connection are required.

Managers register and confirm their email before signing in. Workers use the login credentials created by their manager. Workshop records and photos are stored in Supabase.

The app checks this public repository for updates. You can also choose **App updates** in the app. Each download is checked before the app offers installation.

The `update.json` asset is used by the updater; testers only need the MSI installer. The installer is currently unsigned.

This repository contains distribution information and installers. Application source code and workshop data are not published here.
